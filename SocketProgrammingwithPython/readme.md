# TCP Client-Server Sensor Simulation

### Project Description

This project demonstrates basic TCP socket communication using Python. It consists of a server that listens for connections and a client that simulates a temperature sensor by sending data every 5 seconds.

### How to Run

1. **Start the Server**: Open a terminal and run `python server.py`.
2. **Start the Client**: Open a second terminal and run `python client.py`.

### Test Results

- **Localhost Test**: Success. Client and server communicated on `127.0.0.1`.
- **Second Device Test**: Success. Server ran on a laptop (IP: `192.168.x.x`) and the client connected via a mobile hotspot.
